## 这个仓库是干什么的

一句话：从公开招聘信息里识别苏州高新区及周边数智产业的岗位技能需求，再通过高校学生问卷和访谈了解学生的技能储备，把两端放进同一套能力框架，量出**企业需要什么、学生具备什么、差距在哪里**，据此提出高校、企业和政府都能执行的人才培养建议。

项目的逻辑链只有一条：

```text
研究范围界定
    ↓
企业端招聘信息 ──→ 岗位技能需求画像 ──┐
                                      ├─→ 企业需求—学生储备匹配矩阵
学生端问卷访谈 ─→ 学生技能与培养画像 ──┘                  ↓
                                                  差距解释与优先级
                                                          ↓
                                      政策建议 + 培养建议 + 数据可视化产品
```

只做企业端，会变成招聘网站词频统计；只做学生端，会变成普通问卷报告。
真正的研究价值来自**两端采用同一套能力框架后的可比分析**。

## 快速开始

> 运行环境：Python 3.13，已装 `pyyaml`、`openpyxl`。
> 本机托管路径：`C:/Users/超越自我/.workbuddy/binaries/python/envs/default/Scripts/python.exe`

```bash

# 0) 自测（离线，不访问网络；改过代码后必跑）

# 1) 试跑，不写库

# 2) 正式采集
python -m 招聘采集.run

python -m 招聘采集.run --export-only
```

## 两条红线

**数据合规**
- 只访问公开、无需登录的页面和接口；不绕过登录、验证码、付费墙或反爬
- 遇 401/403/429 或验证码 → 立即停止，记录原因并改用获准来源，**不重试、不绕过**
- 商业平台（BOSS 直聘等）**只做人工抽样，不做任何抓取**
- 不采集和传播个人联系方式；报告中不评价、不曝光单个企业

**数据质量**
- 原始量 ≠ 有效量。报告必须分别说明：原始采集量、去重后量、描述质量合格量、最终纳入量
- 岗位族初筛（关键词匹配）只是**候选建议**，不是最终分类，必须人工复核
- 样本边界如实披露：本研究的结论只适用于指定时间窗、指定公开来源的岗位，不代表苏州全市或全年市场
